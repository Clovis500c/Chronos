Chronos returns a single ready-made instance — `require` it and call methods on it directly, no `.new()` needed.

```lua
type State = {
	Time: number,
	Positions: { [number]: CFrame } -- keyed by UserId
}
```

## Lifecycle

### Start

```lua
Chronos:Start(): ()
```

Starts recording. Server only — warns and returns if called on the client. Safe to call twice, the second call is ignored.

### Stop

```lua
Chronos:Stop(): ()
```

Stops recording, disconnects everything and clears the history.

## Reading the past

### GetTime

```lua
Chronos:GetTime(): number
```

Current server time. Shorthand for `workspace:GetServerTimeNow()`.

### GetState

```lua
Chronos:GetState(Time: number): State?
```

The world state at that time, interpolated between the two surrounding snapshots. Returns `nil` if no history exists yet.

Out-of-range requests are clamped rather than refused: a time older than the oldest snapshot returns the oldest, a time in the future returns the newest.

### GetPositionAt

```lua
Chronos:GetPositionAt(Player: Player, Time: number): CFrame?
```

Convenience wrapper around `GetState` for a single player.

```lua
local Where = Chronos:GetPositionAt(Player, Chronos:GetTime() - 0.5)
```

## Guarding client timestamps

A client tells you when it fired. That number comes from a machine you don't control, so it is never trusted — pick one of these two guards.

<Tabs items={['Reject', 'Clamp']}>
<Tab value="Reject">

```lua
Chronos:IsTimeValid(ClientTime: number): boolean
```

`true` if the timestamp is plausible: not in the future, and not further back than `MaxChronos`. Strict — anything outside the window is thrown away.

```lua
if not Chronos:IsTimeValid(ClientTime) then
	return
end
```

</Tab>
<Tab value="Clamp">

```lua
Chronos:GetSafeDelay(ClientTime: number): number
```

The delay between the timestamp and now, clamped to `[0, MaxChronos]`. Nothing is refused — an impossible timestamp is simply pulled back into the allowed window.

```lua
local Delay = Chronos:GetSafeDelay(ClientTime)
local State = Chronos:GetState(Chronos:GetTime() - Delay)
```

</Tab>
</Tabs>

<Callout title="Which one?">
A player on 400ms ping isn't cheating, they're just lagging. `IsTimeValid` rejects every shot they take, which makes the game unplayable for them. `GetSafeDelay` gives them the best rewind the window allows. Reject if you'd rather be strict, clamp if you'd rather be playable.
</Callout>

## Validating a shot

### ValidateHit

```lua
Chronos:ValidateHit(
	Shooter: Player,
	Origin: Vector3,
	Direction: Vector3,
	ClientTime: number,
	Filter: ((Player) -> boolean)?
): (Player?, RaycastResult?)
```

Casts a ray against the world as it was when the shooter fired. The shooter is always excluded from the targets.

<TypeTable
  type={{
    Shooter: {
      type: 'Player',
      description: 'Who fired. Never hits themselves.',
      required: true,
    },
    Origin: {
      type: 'Vector3',
      description: 'Ray start, sent by the client.',
      required: true,
    },
    Direction: {
      type: 'Vector3',
      description: 'Ray direction. Normalised internally, then scaled to MaxDistance.',
      required: true,
    },
    ClientTime: {
      type: 'number',
      description: "The client's GetServerTimeNow() at the moment of the shot.",
      required: true,
    },
    Filter: {
      type: '(Player) -> boolean',
      description: 'Return true if that player should be hittable.',
      default: 'nil',
    },
  }}
/>

Returns the player hit and the raycast result, or `nil, nil` if nothing was hit.

`Filter` is where your game rules go — teams, alive state, spawn protection. Chronos has no opinion on who counts as a target:

```lua
local Hit, Result = Chronos:ValidateHit(Player, Origin, Direction, ClientTime, function(Target)
	return Target.Team ~= Player.Team
end)
```

<Callout type="info">
`Result` is a normal `RaycastResult`, so `Result.Position` and `Result.Normal` are there if you want to spawn an impact effect at the point of contact.
</Callout>
