Chronos is a server-side lag compensation module for Roblox. It records every player's position several times per second and can reconstruct the world state at any past moment, so a shot can be validated against what the shooter actually saw.

Three files, no dependencies, server only.

## What it solves

Your screen shows other players where they *were* a few frames ago, because the information took time to reach you. You aim perfectly and fire, but on the server they have already moved and the ray passes through empty space. The shot was correct and it still did not register.

Chronos rewinds its position log to the instant the shot was fired, rebuilds where everyone actually was, and judges the ray against that. A player on 200ms who aims correctly hits.

## Install

Download `Chronos.rbxm` from [Releases](https://github.com/Clovis500c/Chronos/releases) and drop it in `ServerStorage`, or copy `src/` by hand.

<Files>
  <Folder name="Chronos" defaultOpen>
    <File name="init.lua" />
    <File name="Config.lua" />
    <File name="Types.lua" />
  </Folder>
</Files>

The module returns a ready-made instance, so there is no `.new()`.

```lua
local Chronos = require(game.ServerStorage.Chronos)

Chronos:Start()
```

## Quick start

<Tabs items={['Server', 'Client']}>
<Tab value="Server">

```lua title="ServerScriptService/Combat.server.lua"
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerStorage = game:GetService("ServerStorage")

local Chronos = require(ServerStorage.Chronos)
local ShootRemote = ReplicatedStorage.Shoot

Chronos:Start()

ShootRemote.OnServerEvent:Connect(function(Player, ClientTime, Origin, Direction)
	if not Chronos:IsTimeValid(ClientTime) then
		return
	end

	local Hit = Chronos:ValidateHit(Player, Origin, Direction, ClientTime)

	if Hit then
		local Humanoid = Hit.Character and Hit.Character:FindFirstChild("Humanoid")
		if Humanoid then
			Humanoid:TakeDamage(25)
		end
	end
end)
```

</Tab>
<Tab value="Client">

```lua title="StarterPlayerScripts/Shooting.client.lua"
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local UserInputService = game:GetService("UserInputService")

local ShootRemote = ReplicatedStorage.Shoot
local Camera = workspace.CurrentCamera

UserInputService.InputBegan:Connect(function(Input, Processed)
	if Processed or Input.UserInputType ~= Enum.UserInputType.MouseButton1 then
		return
	end

	local Mouse = UserInputService:GetMouseLocation()
	local Ray = Camera:ViewportPointToRay(Mouse.X, Mouse.Y)

	ShootRemote:FireServer(workspace:GetServerTimeNow(), Ray.Origin, Ray.Direction)
end)
```

</Tab>
</Tabs>

<Callout type="warn" title="Use the right clock">
The timestamp **must** come from `workspace:GetServerTimeNow()`. It's the only clock that reads the same on both sides. `tick()`, `os.time()` and `os.clock()` measure local machine time and will produce wrong results.
</Callout>

`IsTimeValid` rejects anything beyond `MaxChronos` (0.3s by default), which also caps what a spoofed timestamp can reach. If you'd rather clamp than reject laggy players, use `GetSafeDelay` instead. See the [API reference](/docs/api).
